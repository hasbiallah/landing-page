## Problem Statement

Landing page hasbi.dev menjual tiga paket layanan (Hemat Rp299rb, FYP Rp990rb, Cuan Rp2.5jt) untuk Bot WhatsApp & Website UMKM, tetapi **produk yang dijual belum ada**. Saat ini, jika ada customer yang tertarik dan chat WA, tidak ada sistem yang bisa di-deliver.

Pain points:
1. **Tidak ada produk untuk di-deliver** — landing page live, tapi tidak ada bot WhatsApp atau landing page builder yang bisa dikasih ke customer.
2. **Manual setup tidak scalable** — kalau setup manual per customer (install library, config server, deploy), effort tinggi dan tidak profitable di harga Rp299rb-2.5jt.
3. **Tidak ada differentiator** — banyak kompetitor jual bot WA (Qontak, Wati, dll), tapi semuanya SaaS subscription bulanan. Hasbi.dev perlu unique positioning: **one-time payment, fully owned by customer, no recurring fee**.

## Solution

Bangun **dua produk terpisah** yang bisa di-mix-and-match sesuai paket:

### 1. **WhatsApp Bot Engine** (core product)
- Self-hosted bot WhatsApp berbasis [whatsapp-web.js](https://github.com/pedroslopez/whatsapp-web.js) atau [Baileys](https://github.com/WhiskeySockets/Baileys)
- Auto-reply berdasarkan keyword matching
- Broadcast message ke daftar kontak
- CLI tool untuk generate config + Docker Compose setup
- Customer deploy di VPS sendiri (DigitalOcean, AWS, Contabo, dll)
- **Deliverable**: Git repo private + dokumentasi setup + 1x free onboarding call

### 2. **Landing Page Builder** (add-on untuk paket FYP & Cuan)
- Template Astro statis dengan Tailwind (mirip landing page hasbi.dev ini)
- CLI tool untuk generate landing page dari config YAML
- Sections: Hero, Katalog Produk, Testimoni, FAQ, CTA WA
- Deploy ke Vercel/Netlify via Git (gratis tier cukup untuk UMKM)
- **Deliverable**: Git repo private + deploy key Vercel + dokumentasi

### 3. **Katalog Produk Digital** (add-on untuk paket FYP & Cuan)
- Halaman katalog produk statis (gambar, deskripsi, harga, tombol WA)
- Data produk dari JSON/YAML, di-render via Astro
- Tidak ada cart/checkout — semua transaksi via WhatsApp
- **Deliverable**: Integrasi di landing page builder

## Scope Produk

### A. WhatsApp Bot Engine (Paket Hemat, FYP, Cuan)

**Fitur Core**:
- **Keyword-based auto-reply**: user kirim keyword (case-insensitive), bot reply dengan message yang sudah di-config
- **Multi-keyword support**: Hemat = 5 keywords, FYP = 20 keywords, Cuan = unlimited
- **Broadcast message**: kirim pesan ke list nomor (Cuan only)
- **Session persistence**: bot reconnect otomatis kalau restart
- **Webhook support** (optional): POST event ke URL eksternal (untuk future integration)

**Tech Stack**:
- **Library**: [Baileys](https://github.com/WhiskeySockets/Baileys) (lebih stabil dari whatsapp-web.js, tidak butuh browser/Chromium)
- **Runtime**: Node.js 20+
- **Database**: SQLite (untuk session persistence & contact list)
- **Config**: YAML file (`bot-config.yml`)
- **Deployment**: Docker Compose (1-command setup)
- **VPS**: DigitalOcean Droplet $6/month (1GB RAM cukup)

**Config Structure** (`bot-config.yml`):
```yaml
bot:
  name: "Toko Sayaaa Bot"
  phone_number: "6281234567890"  # nomor WA customer
  
keywords:
  - trigger: ["harga", "price", "berapa"]
    reply: |
      Halo! Harga produk kami:
      - Paket A: Rp50.000
      - Paket B: Rp100.000
      Mau order? Ketik "order" ya!
      
  - trigger: ["alamat", "lokasi", "address"]
    reply: "Alamat kami: Jl. Contoh No.123, Jakarta Selatan"
    
  - trigger: ["katalog", "produk", "menu"]
    reply: "Cek katalog lengkap di: https://tokosayaaa.com/katalog"
    
broadcast:
  enabled: true  # Cuan only
  contacts_file: "contacts.txt"  # 1 nomor per line
```

**CLI Tool** (`hasbi-bot`):
```bash
# Install CLI
npm install -g @hasbidev/whatsapp-bot-cli

# Generate new bot project
hasbi-bot init --package hemat --phone 6281234567890
# Output: bot-toko-sayaaa/ dengan Dockerfile, docker-compose.yml, bot-config.yml

# Start bot (di VPS customer)
cd bot-toko-sayaaa/
docker-compose up -d

# Scan QR code untuk login WA (1x saja)
docker-compose logs -f bot
# Scan QR dengan HP, session tersimpan di SQLite

# Update config
nano bot-config.yml
docker-compose restart bot

# Broadcast (Cuan only)
hasbi-bot broadcast --message "Promo Hari Ini: Diskon 50%!" --contacts contacts.txt
```

**Deliverable per Paket**:
- **Hemat**: Git repo private dengan `bot-config.yml` (5 keywords pre-filled), Dockerfile, README.md, 1x onboarding call (30 menit via Zoom)
- **FYP**: Git repo private dengan `bot-config.yml` (20 keywords pre-filled), Dockerfile, README.md, 1x onboarding call (45 menit)
- **Cuan**: Git repo private dengan `bot-config.yml` (unlimited, pre-filled 30+ keywords), Dockerfile, broadcast script, README.md, 2x onboarding call (1 jam total), revisi config unlimited

## Implementation Decisions

### Kenapa Baileys, Bukan whatsapp-web.js?

| Aspect | Baileys | whatsapp-web.js |
|--------|---------|-----------------|
| Browser dependency | ❌ None (native protocol) | ✅ Chromium (high RAM) |
| RAM usage | ~150MB | ~500MB |
| Stability | ✅ Lebih stabil, reconnect otomatis | ⚠️ Sering crash di VPS low-spec |
| Active maintenance | ✅ Ya (2024+) | ⚠️ Less active |
| WhatsApp ban risk | ⚠️ Sama (unofficial API) | ⚠️ Sama |

**Decision**: Baileys untuk v2.0. Lebih cocok untuk VPS $6/bulan (1GB RAM). Future: evaluasi [WhatsApp Business API](https://business.whatsapp.com/products/business-platform) kalau customer willing bayar $0.005-0.01/message (unlikely untuk Paket Hemat/FYP).

### Kenapa Docker Compose, Bukan PM2/Systemd?

- **Docker**: 1-command setup (`docker-compose up -d`), reproducible, easy rollback, no conflict dependency Node.js
- **PM2/Systemd**: butuh install Node.js manual, risk version conflict, harder untuk customer non-teknis

**Decision**: Docker Compose. Customer cukup install Docker (via `curl -sSL https://get.docker.com | sh`), no need deep Linux knowledge.

### Kenapa Config YAML, Bukan Database/CMS?

- **YAML**: Simple, version control friendly (Git), no database overhead
- **CMS (Strapi, Payload)**: Overkill untuk 5-20 produk, butuh server/database tambahan, kompleksitas tinggi

**Decision**: YAML untuk v2.0. Future (v2.1+): evaluasi headless CMS kalau customer request UI untuk edit konten (unlikely untuk target UMKM kecil).

### Kenapa One-Time Payment, Bukan SaaS Subscription?

**Positioning differentiation**:
- Kompetitor (Qontak, Wati, Tawk.to): subscription Rp200rb-500rb/bulan = Rp2.4jt-6jt/tahun
- Hasbi.dev: one-time Rp299rb-2.5jt = owned selamanya (selama VPS customer bayar $6/bulan ke DigitalOcean)

**Pros**:
- Target UMKM kecil (omzet <Rp10jt/bulan) lebih suka one-time payment
- Customer full control data (no vendor lock-in)
- Scalability: hasbi.dev tidak perlu maintain infrastructure customer long-term

**Cons**:
- No recurring revenue untuk hasbi.dev (hanya dapat sekali bayar)
- Customer perlu bayar VPS sendiri ($6/bulan = Rp90rb/bulan)

**Decision**: One-time payment untuk v2.0. Positioning sebagai "bot WhatsApp yang fully owned, no subscription". Future revenue dari addon/upgrade (misal: "upgrade bot Hemat ke FYP" = top-up Rp700rb).

## Out of Scope (v2.0)

- **WhatsApp Business API official** (biaya per-message, overkill untuk target UMKM kecil)
- **Payment gateway integration** (semua transaksi manual via WA untuk v2.0)
- **Order dashboard/CRM** (no backend, all static)
- **Multi-agent bot** (bot hanya 1 nomor, tidak ada routing/queue)
- **AI/NLP auto-reply** (keyword matching cukup untuk v2.0, AI mahal & overkill)
- **Mobile app** (landing page mobile-responsive cukup)
- **WhatsApp Shop integration** (belum mature, FB Business Manager ribet)

## Risks & Mitigation

| Risk | Impact | Mitigation |
|------|--------|-----------|
| **WhatsApp ban unofficial API** | 🔴 High — customer kehilangan bot | Dokumentasi: "gunakan nomor WA baru, bukan nomor bisnis utama". Sediakan migration guide ke WA Business API kalau di-ban. |
| **Customer tidak bisa deploy sendiri** | 🟡 Medium — hasbi.dev harus manual setup | Video tutorial step-by-step + offering paid setup service (+Rp200rb). |
| **VPS customer crash/down** | 🟡 Medium — bot offline, customer komplain | Dokumentasi monitoring (UptimeRobot free tier) + auto-restart via Docker restart policy. |
| **Competitor copy positioning** | 🟢 Low — sulit replicate "fully owned" | Build brand trust via social proof & portofolio real customer. |

## Further Notes

- **Dokumentasi critical**: Target customer adalah UMKM owner yang minimal teknis. Video tutorial + screenshot step-by-step wajib ada, bukan hanya text README.
- **Onboarding call wajib**: Paket Hemat/FYP minimal 30-45 menit call untuk guide setup pertama. Paket Cuan 2x call (1 jam total) untuk diskusi bisnis flow + customization.
- **Testimoni real dari early bird**: Sebelum official launch, ambil 2-3 early bird gratis/diskon untuk build portofolio & social proof (sesuai ADR-0004).
- **Future monetization**: Setelah v2.0 stable, bisa offering addon berbayar: upgrade Hemat→FYP (top-up Rp700rb), maintenance VPS bulanan (Rp300rb/bulan), custom fitur bot (Rp1jt+).
