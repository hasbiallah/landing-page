## Problem Statement

Landing page hasbi.dev menjual tiga paket layanan (Hemat Rp299rb, FYP Rp990rb, Cuan Rp2.5jt) untuk Bot WhatsApp & Website UMKM, tetapi **produk yang dijual belum ada**.

Constraint tambahan: **Semua harus bisa deploy gratis di Vercel**, tidak boleh butuh VPS berbayar ($6/bulan terlalu mahal untuk early stage).

## Revised Solution: Serverless WhatsApp Bot + Static Landing

### Challenge: WhatsApp Bot di Vercel Serverless

WhatsApp bot tradisional (Baileys/whatsapp-web.js) butuh **long-running process** untuk maintain WebSocket connection — **tidak compatible dengan Vercel serverless** (max 10s execution, no persistent connection).

### Alternative Approach: Webhook-Based Bot via WhatsApp Business API

**Option 1: WhatsApp Business Cloud API (Meta)**
- ✅ Webhook-based (cocok serverless)
- ✅ Official API (tidak ada risk ban)
- ❌ **Gratis hanya 1,000 conversations/bulan** (setelah itu $0.005-0.01/message)
- ❌ Butuh Facebook Business Manager verification (ribet untuk UMKM kecil)

**Option 2: WhatsApp via Third-Party Gateway (Fonnte, Wablas, dll)**
- ✅ Webhook-based (cocok serverless)
- ✅ Setup mudah (API key only)
- ❌ **Tidak gratis** — Fonnte = Rp150rb/bulan, Wablas = Rp99rb/bulan minimum
- ❌ Tidak "fully owned" (masih depend on service)

**Option 3: Hybrid — Bot Engine as Separate Product (Not Hosted by Hasbi.dev)**

Re-scope: **Hasbi.dev tidak host bot customer**. Bot tetap self-hosted di environment customer, tapi saya sediakan:
1. **Docker image ready-to-deploy** (customer bisa deploy di Railway.app, Render.com, Fly.io — semua ada free tier)
2. **Landing page builder di Vercel** (gratis selamanya)

Customer bayar hosting bot sendiri (atau pakai free tier Railway/Render), tapi hasbi.dev hanya deliver:
- Source code bot + Docker image
- Landing page deployed di Vercel
- Dokumentasi deploy

**Deliverable**: Git repo private + Docker image + dokumentasi

Customer deploy sendiri di:

- **Storage**: SQLite volume (untuk session persistence)
- **Config**: Environment variables + YAML file di Git repo

**Setup Flow**:
1. Hasbi.dev deliver Git repo ke customer
2. Customer fork repo ke GitHub mereka
3. Customer connect GitHub ke Railway/Render (1-click deploy)

**Pros**:
- Customer full control (self-hosted, bukan SaaS hasbi.dev)

**Cons**:
- Customer perlu punya akun Railway/Render (tapi signup gratis)

## Tech Stack Detail

### WhatsApp Bot Engine

```
Tech: Node.js 20 + Baileys + SQLite
Deployment: Railway.app / Render.com / Fly.io (Docker)
Storage: Volume mount untuk SQLite session.db (persist on restart)
Environment: .env file untuk config (WA phone number, keywords)
Monitoring: UptimeRobot free tier (ping /health endpoint setiap 5 menit)
```

**bot-config.yml** example:
```yaml
bot:
  name: "Toko Sayaaa Bot"
  phone: "6281234567890"
  
keywords:
  - trigger: ["harga", "price", "berapa"]
    reply: |
      Halo! Harga produk kami:
      - Paket A: Rp50.000
      - Paket B: Rp100.000
      Ketik "order" untuk pesan!
      
  - trigger: ["alamat", "lokasi"]
    reply: "Alamat: Jl. Contoh No.123, Jakarta Selatan"
    
  - trigger: ["katalog", "produk"]
    reply: "Cek katalog lengkap: https://toko-sayaaa.vercel.app"
    
broadcast:
  enabled: true  # Cuan only
  contacts: []   # list nomor WA
```

**Dockerfile**:
```dockerfile
FROM node:20-slim
WORKDIR /app
COPY package*.json ./
RUN npm ci --production
COPY . .
VOLUME /app/session
CMD ["node", "index.js"]
```

**Railway.app deployment**:
- Connect GitHub repo
- Auto-detect Dockerfile
- Add volume `/app/session` (untuk SQLite persist)
- Environment variable: `WA_PHONE=6281234567890`
- Deploy (auto-run Docker container)
- Logs menampilkan QR code untuk scan (1x saja)

**Free tier limit**:
- Railway: 500 jam/bulan = ~16 hari (setelah itu sleep, perlu upgrade $5/month)
- Render: 750 jam/bulan = ~25 hari (setelah itu sleep)
- Fly.io: 3 shared VMs gratis (tapi kompleksitas setup lebih tinggi)

## Pricing Justification (Kenapa Rp299rb-2.5jt untuk Setup Gratis?)

Customer bayar untuk:
1. **Setup & customization time** — hasbi.dev setup repo, config, dan customization per customer (2-4 jam effort)
2. **Template & codebase** — kode bot + landing page template (developed by hasbi.dev, bukan generic open-source)
3. **Documentation & onboarding** — video tutorial, README step-by-step, dan 1-2x Zoom call onboarding
4. **Copywriting (Paket Cuan)** — headline hook, product description persuasif, FAQ lengkap (value tinggi)
5. **Revisi & support** — 1x revision (FYP) atau unlimited (Cuan)

**One-time payment positioning**:
- Kompetitor SaaS (Qontak, Wati): Rp200rb-500rb/bulan = Rp2.4jt-6jt/tahun recurring
- Hasbi.dev: Rp299rb-2.5jt sekali, owned selamanya (customer hanya bayar hosting $0-5/bulan ke Railway/Vercel)

## Risks & Mitigation

| Risk | Impact | Mitigation |
|------|--------|-----------|
| **Railway/Render free tier sleep setelah idle** | 🟡 Medium — bot offline kalau tidak ada traffic | Dokumentasi: setup UptimeRobot gratis (ping /health setiap 5 menit keep bot awake). Atau recommend customer upgrade $5/month. |
| **Customer tidak bisa setup GitHub + Railway** | 🟡 Medium — hasbi.dev harus manual setup | Offering paid setup service (+Rp200rb untuk Paket Hemat/FYP). Video tutorial sangat jelas. |
| **WhatsApp ban unofficial API** | 🔴 High — customer kehilangan bot | Dokumentasi: "gunakan nomor WA baru, bukan nomor bisnis utama". Sediakan migration path ke WA Business Cloud API. |
| **Vercel bandwidth limit (100GB/bulan)** | 🟢 Low — jarang terlampaui untuk UMKM kecil | Monitor Vercel analytics, recommend Cloudflare CDN kalau traffic tinggi. |
