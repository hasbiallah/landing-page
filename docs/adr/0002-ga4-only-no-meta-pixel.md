# GA4 saja, tanpa Meta Pixel di v1

Traffic awal dari organik dan word-of-mouth, bukan paid ads. Meta Pixel tanpa campaign aktif tidak memberikan nilai apapun dan hanya menambah beban script. GA4 sudah cukup untuk track KPI utama: klik tombol WA, scroll depth, dan waktu di halaman. Meta Pixel ditambahkan nanti ketika kampanye Meta Ads siap dijalankan.
